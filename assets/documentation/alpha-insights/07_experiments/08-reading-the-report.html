Reading the Report

Open Alpha Insights → Experiments → Report (also under Website Traffic as A/B Experiments). The Experiments list shows the same warehouse metrics for all time. The report is date-filtered (default last 30 days) and includes charts plus a full variant table.

You can filter the report to one or more experiments from the filters modal (Pro for custom filter sets, same as other reports).

Headline metrics

Metric What it measures
Exposures Assigned visitors who saw a variant. This is the conversion-rate denominator.
Conversions Exposed visitors who completed the experiment’s primary goal.
Conversion rate Conversions ÷ exposures.
Lift vs control How far a treatment’s conversion rate sits above or below that experiment’s own control. Control is not given a lift.
Add to carts / initiate checkouts / transactions Funnel counts from the same exposed sessions. Rates are also available as % of exposures.
Sessions / duration Analytics sessions joined to exposed assignments.

Pro-only columns

  • Revenue and AOV — from attributed purchases (session events, with visitor-ID fallback on the order).
  • Profit — store profit for those attributed sessions / orders.
  • Significance — scored against that experiment’s control, even if more than one test is in the date range. Confidence interval columns appear on the variant table when Pro is active.

Charts

  • Hits per experiment — exposures over time, grouped by experiment.
  • Conversion rate by variant — includes control so you can compare arms on the same axis.
  • Daily lift vs control — treatment arms only.

How to read a result

  1. Confirm both arms have meaningful exposures. Very small samples swing wildly.
  2. Compare conversion rate and lift, not raw conversions, if traffic is slightly uneven.
  3. Use the funnel (add to cart → initiate checkout → purchase) to see where a treatment helps or hurts.
  4. In Pro, wait for significance before you ship a small lift. A “leading” badge on the list is only the current highest rate, not a statistical call.
  5. If the list and report disagree, check the report date range. The list is all-time.

Metric names in Report Builder

Experiment fields are labelled with an Experiment - prefix in pickers so they stay distinct from website traffic and orders. You can add them to custom reports the same way as other warehouse entities.
